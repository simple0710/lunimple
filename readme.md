# 🚀 Lunimple

AtCoder 등 알고리즘 문제 풀이 데이터를 기반으로 사용자의 취약점을 분석하고 맞춤형 문제를 추천하는 알고리즘 학습 플랫폼입니다.

---

## 📘 프로젝트 진행 기간

개인 프로젝트

2026.05.18 ~ 2026.06.07 (3주)

---

## 🔎 개요

Lunimple은 단순히 문제를 나열하는 플랫폼이 아니라, 사용자의 제출 기록과 풀이 성과를 분석하여 부족한 역량을 파악하고 성장에 필요한 문제를 추천하는 서비스입니다.

사용자는 자신의 문제 풀이 현황을 확인하고, 취약 유형을 기반으로 추천된 문제를 해결하며 체계적으로 알고리즘 실력을 향상시킬 수 있습니다.

---

## 💎 주요 기능

### 👤 사용자 정보 조회

#### 1. 사용자 프로필 조회

* 핸들
* 레이팅
* 총 풀이 수
* 대회 참가 횟수

를 확인할 수 있습니다.

---

### 📊 문제 풀이 통계

#### 1. 전체 문제 풀이 현황

* 전체 풀이 수
* 정답 수
* 오답 수
* 성공률

을 제공합니다.

#### 2. 난이도별 통계

사용자의 난이도별 풀이 현황을 분석합니다.


구간별 성공률과 풀이 수를 확인할 수 있습니다.

---

### 🎯 취약점 분석

#### 1. 취약 유형 분석

사용자의 제출 기록을 기반으로

* 대화 난이도 성과

등 알고리즘 유형별 성과를 분석합니다.

#### 2. Weakness Score 산출

성공률과 풀이 수를 기반으로 취약도를 계산하여 사용자에게 제공합니다.

---

### 🧩 문제 추천

#### 1. 필수 추천 문제

취약도가 높은 유형을 우선적으로 보완할 수 있는 문제를 추천합니다.

#### 2. 추가 추천 문제

사용자의 현재 레이팅과 풀이 이력을 고려하여 성장에 도움이 되는 문제를 추천합니다.

#### 3. 추천 결과 조회

추천된 문제 목록과 추천 사유를 확인할 수 있습니다.

---

### 🏆 대회 정보 조회

#### 1. 대회 목록 조회

참여 가능한 알고리즘 대회를 확인할 수 있습니다.

#### 2. 대회 상세 정보 조회

* 대회 이름
* 시작 시간
* 종료 시간

를 제공합니다.
